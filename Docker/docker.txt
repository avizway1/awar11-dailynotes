Microservices 

================================================


Physical Server : Hardware, Network, OS, librariers, Runtime, Application / Code..
Security, Maintenance, cooling, Power COnnection/UPS, 
problem : 	Time, Money - Upfront, 
			Scaling - Vertical ( Adding more RAM / CPU on Same server) / Horizontal (Adding more servers).



Monolith : 
- Slow and Risky Releases - every change ships with every other change. 
- All - or - Nothing Scaling - scale the entire application. 
- One bug takes down everything - a memory leak in the cart module crashes payments and order services also. 
- Locked into one technology: you struck with one language and one framework for total application. 

Microservices : 
- Independent Deployment : Payments- Deployment
- Targeted Scaling : More load on payments- scale only payments
- Fault isolation : if the recommendation service fails, the customer can still browse and pay. 
- Right tool per job : python for ML, Go - apigw, Java - billing..
- Small, owning teams
- Easier to understand
