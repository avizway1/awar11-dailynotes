git merge : `git merge` brings all changes together. This is a very simple and safe approach for repositories where multiple developers are working (shared repositories). 


Assume you and your frined writing a book and it has 6 chapters.. YOU: 3 chapters.. YOUR FRIEND: 3 chapters..

MERGE: 
- You wrote three chapters. 
- Your friend wrote three chapters at the same time.
You both decided to combine. 
--> If you merge, It shows as you wrote 3 chapters and your friend wrote 3 chapters.
--> Merge keeps all original commit hashes.

REBASE: `git rebase` rewrites all the changes. It is not a recommended approach for shared repositories. 
- Whenever you are working primarily in your local repositories, you can use this to reduce the commit count. 

- You wrote three chapters. 
- Your friend wrote three chapters at the same time.
You both decided to combine. 
--> It shows your three chapters first, then your friend's three chapters, for a clean and linear history. 


THUMB RULE : Never rebase shared or public repositories. It may override others' work. 
- It changes commit hashes.
- It destroys teammates' base history.
- It multiplies duplicate commits.
- It requires dangerous force pushing.

git stash : 

Imagine you are working on some changes and suddenly your team member asks you to switch to another branch to fix a very important or critical bug. 

- If your changes areunfinished changes, you can't commit them but you don't want to lose them. 

--> We can stash them, we can switch to other branch, once the work completed, We can switch back to our branch, Then we can unstash it.


git stash					- stash the changes
git stash apply				- apply the stashed changes
git stash list				- list the stashes
git stash show -p			- show stash content
git stash pop				- apply and remove the stash
git stash push -m "msg"		- create a stash with custom msg


echo "STASH-Test" > main.txt && git add . && git commit -m "stash test"


echo "STASH" >> main.txt && git add . && git commit -m "C2"

Please commit your changes or stash them before you switch branches.
