E : Effect : Allow / Deny			: Deny
A : Actions : s3:* 					: Everything on S3
R : Resources : *					: All resources

ARN : Amazon Resource Name : This gives uniqueness to the AWS component.


{
	"Version": "2012-10-17",
	"Statement": [
		{
			"Sid": "VisualEditor0",
			"Effect": "Deny",
			"Action": "s3:*",
			"Resource": "*"
		}
	]
}



Explicit Deny: Explicitly we are denying S3, So DENY will have highest priority always. 
(User level, Group level, Resource level --> DENY will have priority).
You allow 100 times but deny 1 time at any level --> DENY takes effect.
