DHCP : Dynamic Host Configuration Protocol : this is a network management protocol that automatically assigns an IP address to the device added to the network. 
DHCP will have an IP address pool. One of the IPs will be picked and will be allocated to the newly added device. 


D-O-R-A : 

Discover : The device or client broadcasts a message to find available DHCP servers on the network. 
Offer : DHCP server responds with a temporary IP address allocation offer. 
Request : the client officially requests the offered IP address from the server. 
Acknowledge : the DHCP server sends the final confirmation. Officially the IP address will be allocated with a lease period.

Network ACLs : NACLs : 

By default, all subnets will be part of default NACLs. All traffic is allowed and no filters applies on defualt NACLs. 

Security groups are stateful, Means... We need to take care about the inbound rules only.. outbound will be allowed automatically as system remembers the traffic flow. 
--> SGs support only ALLOW operation, We cannot perform explicit DENY with SG.
--> SGs works at instance level.

NACLs are stateless, Means.. We need to take care about the inbound and outbound rules.. NACLs dont remeber the incoming and outgoing request flow.
--> NACLs works at subnet level.
--> NACLs supports ALLOW and DENY options.


Inbound : You define exactly what traffic can ENTER the instance/Subnet. 
Outbound : You define exactly what traffic can LEAVE the instance/Subnet.

Ephemeral Port : When traffic leave the subnet to respons to the request, it does not go out on port 80, it picks a dynamic ephemeral port assigned by Client OS. 

One subnet can be member of only 1 NACL at a time.
