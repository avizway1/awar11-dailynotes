DHCP : Dynamic Host Configuration Protocol : this is a network management protocol that automatically assigns an IP address to the device added to the network. 
DHCP will have an IP address pool. One of the IPs will be picked and will be allocated to the newly added device. 


D-O-R-A : 

Discover : The device or client broadcasts a message to find available DHCP servers on the network. 
Offer : DHCP server responds with a temporary IP address allocation offer. 
Request : the client officially requests the offered IP address from the server. 
Acknowledge : the DHCP server sends the final confirmation. Officially the IP address will be allocated with a lease period.

IPv4 is 32 bit.. 

/32	--> 32 - 32 = 0 = 2^0 = 1
/31	--> 32 - 31 = 1 = 2^1 = 2
/30 --> 32 - 30 = 2 = 2^2 = 4
/29 --> 32 - 29 = 3 = 2^3 = 8
/28 --> 32 - 28 = 4 = 2^4 = 16			--> Min CIDR Range VPC Supports

/24 --> 32 - 24 = 8 = 2^8 = 256

/20 --> 32 - 20 = 12 = 2^12 = 4096

/16 --> 32 - 16 = 16 = 2^16 = 65536		--> Max CIDR Range VPC Supports

/0 --> 32 - 0 = 32 = 2^32 = 4294967296 IPs

===========

We cannot use all the above IPs.. 

In general networks two IPs will be reserved:
1. The first IP represents the network ID.
2. The last IP represents the broadcast ID.

Along with the above two, AWS reserves three more IP addresses so a total of five IP addresses will be reserved if we are creating networks in AWS. 
3. VPC Router
4. AWS VPC DNS
5. For Future usage
