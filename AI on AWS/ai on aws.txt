TOKEN: 
LLMs don't read the whole world. They break the text into tokens. Roughly one token is approximately four characters. 100 tokens come near 75 words. 

EMBEDDING : an embedding turns text into a list of numbers that capture its meaning. Text with similar meaning gets a similar number. 

CONTEXT WINDOW : so how much can the model consider at once when it is giving a reply? Memory of that particular chart window: a bigger window remembers more information about that chart or the work we are performing. 
-> Perform compaction periodically so that you can save a lot of tokens. 
-> A lot of modern AI tools are supporting 1 million-token context windows. 

Prameters (Weights) : a parameter is like learned knowledge. More parameters generally mean more capability but also more compute and cost. 
- We can run a 3-billion-parameter model on our laptop. 
- A bigger model runs on huge compute capacity devices.

Temperature : it ranges from 0 to 1 in most of the cases. Temperature is a configuration parameter that controls an LLM's creativity and predictability of output during inference. 

0.0 - 0.3 : Low temperature : deterministic and precise 
0.5 - 0.7 : medium temperature: Balanced, a mix of accuracy and natural flow. 
0.8 - 1.0+ : Creative and random. It chooses less predictable words but has a very high chance of hallucinations.
