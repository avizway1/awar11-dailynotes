

Introduction to AI (Artificial Intelligence) : AI is software that does things we normally think need human intelligence. 
- Face unlock
- Recommending a movie
- Writing an email with autocorrect

Old software follows the instructions that we configure in a programme. 
Voter ID : if >=18, you are allowed to vote, else You need to wait till you turn 18.

AI is a bit different. We don't define the rules. We show it examples and AI figures out the rules itself. 

10,000 cat photos and label it as "cat" - AI learns what a cat looks like. 
No one writes a definition of cat. AI learns from the example. 


- AI learns from data. It doesn't follow handwritten rules.

CPU : central processing unit. It is a general-purpose processor designed to handle a wide variety of regular tasks. We will have some powerful cores in it. 
- 2 core - 64 cores per chip
- Serial execution
- Massive data cache (L1, L2, L3)

GPU : graphics processing unit. It's a highly specialised processor designed to execute thousands of simple repetitive tasks simultaneously using a massive array of similar cores. 
- 5,000 - 16,000+ cores
- Parallel execution
- VRAM - Stream bulk data 


Data (internet) + Compute (gpu) + Transformer (Architecture) = AI Boom

TOKEN: 
LLMs don't read the whole world. They break the text into tokens. Roughly one token is approximately four characters. 100 tokens come near 75 words. 

EMBEDDING : an embedding turns text into a list of numbers that capture its meaning. Text with similar meaning gets a similar number. 

CONTEXT WINDOW : so how much can the model consider at once when it is giving a reply? Memory of that particular chart window: a bigger window remembers more information about that chart or the work we are performing. 
-> Perform compaction periodically so that you can save a lot of tokens. 
-> A lot of modern AI tools are supporting 1 million-token context windows. 

Prameters (Weights) : a parameter is like learned knowledge. More parameters generally mean more capability but also more compute and cost. 
- We can run a 3-billion-parameter model on our laptop. 
- A bigger model runs on huge compute capacity devices.
