

On-Premise Self Hosted Database : Hardware, OS Seleciton, OS Patching, DB HA, DB Backups.. 
EC2 Instance Hosted DB : Hardware, OS --> AWS Responsibility.. OS Patching, HA, FT, Backups..
Amazon RDS Hosted DB : Everything AWS Manages.. Choose DB Engine.. Enable features based on requirement.. 

Relational Database : Structures schema + Relationships.. Data stores in Table format (Rows & Columns).. Banking, ERP, Transactions..  RDS.. 
Non-Relational Database : JSON Format (Key and Value)..  Flexible schema.. Web apps, user profiles, Catalog, IoT.. DynamoDB
Graph DB : Neo4j, Amazon Nepture.. Designed for connected data.. Social networking, Fraud Detection.. Recommendations..

RDS : AWS SUpports 7 DB Engines..

1. Amazon Aurora (Mysql Compatbale edition & PostGreSQL Compatable)
2. MySQL : 3306 							: mysql workbench / dbeaver
3. PostgreSQl : 5432 						: PGAdmin
4. Microsoft SSQL : 1433 					: SSMS (SQL Server Management Studio)
5. MariaDB : 3306 							: Workbecnh
6. Oracle DB : 1521 						: sql developer / Toad
7. IBM DB2 : 50000 (Non-ssl), 50001 (SSl)	: IBM Enterprise Tool
