

YAML has 4 golden rules.

1. indentation = structure			==> YAML has no { } brackets. Spaces decide who is parent and who is the child.
2. Spaces only						==> use 2 spaces or set VCCode to use spaces when you hit tab
3. space after colon				==> name: avinash (valid)
4. Case sensitive					==> Resources ≠ resources

name:avinash	--> One string only
name: avinash	--> valid key and value
